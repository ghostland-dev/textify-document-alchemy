# PDF-kit

Document toolbox: convert, merge and split PDFs.

## Features

- PDF to text and other formats
- Text/Markdown to PDF
- Merge and split PDFs

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router
- Supabase
- jsPDF

## Getting Started

```bash
git clone https://github.com/ghostland-dev/textify-document-alchemy.git
cd textify-document-alchemy
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
